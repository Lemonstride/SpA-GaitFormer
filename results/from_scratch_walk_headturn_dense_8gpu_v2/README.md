# Final Dense Head-Turn Result

This directory contains the concise, privacy-preserving acceptance summary for
the completed 80%-overlap matrix. The full run contains 40 checkpoints and
associated manifests, histories, logs, and prediction files and remains in the
user-owned AML experiment directory.

See [`FINAL_ACCEPTANCE_SUMMARY.json`](FINAL_ACCEPTANCE_SUMMARY.json) for the
reported participant-level estimates and [`../../docs/DENSE_HEADTURN_EXPERIMENT.md`](../../docs/DENSE_HEADTURN_EXPERIMENT.md)
for the protocol and interpretation boundaries.

The result is accepted as an executed small-cohort sensitivity analysis. It is
not accepted as evidence of participant-level clinical efficacy.
